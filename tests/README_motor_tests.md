# モーターテストツール

`run_manual.py`や`constants.py`を変更せずにモーター性能をテストするツール群です。

## 📋 前提条件

⚠️ **重要**: 全てのテストは**車輪を浮かした状態**で実行してください

## 🚀 使用方法

### 1. 簡易テスト (推奨)
```bash
cd tests
python quick_motor_test.py
```

### 2. 包括的テスト
```bash
cd tests
python test_motor_limits.py
```

### 3. 🆕 機体間比較テスト
```bash
cd tests
# 詳細比較 (推奨)
python compare_robots.py

# クイック比較 (5分で完了)
python quick_compare.py
```

## 🤖 機体比較機能の特徴

### 詳細比較 (`compare_robots.py`)
- **完全自動化**: 2台の機体を順次テスト
- **7項目評価**: 速度、安定性、効率性、達成率、一貫性、バッテリー、総合スコア
- **科学的判定**: 統計的根拠に基づく優劣判定
- **推奨事項**: バッテリー状態やメンテナンス項目を自動提案

### クイック比較 (`quick_compare.py`)
- **高速テスト**: 各機体5秒間で完了
- **6項目評価**: 重要指標のみに絞った効率的評価
- **即座判定**: リアルタイムで優劣を表示

## 📊 比較評価項目

### 1. **平均速度** (高いほど良い)
- 設定値98での実際の速度

### 2. **安定性** (低いほど良い)
- 速度変動の少なさ

### 3. **効率性** (高いほど良)
- 消費パワーあたりの速度

### 4. **達成率** (高いほど良い)
- 設定値に対する実現率

### 5. **一貫性** (低いほど良い)
- 複数テスト間でのバラつき

### 6. **バッテリー状態**
- 電圧レベルの比較

### 7. **総合スコア**
- 全項目を重み付けした総合評価

## 💡 機体比較の使い分け

### 詳細比較向き
- ✅ 競技用機体の選定
- ✅ メンテナンス効果の確認
- ✅ 部品交換前後の比較
- ✅ 科学的データが必要な場合

### クイック比較向き
- ✅ 練習前の機体選択
- ✅ バッテリー交換後の確認
- ✅ 素早い動作確認
- ✅ 時間が限られている場合

## 🔧 テスト結果の活用

### 1. **機体選定**
- 競技本番用の機体決定
- バックアップ機体の準備

### 2. **メンテナンス指針**
- 劣る項目の特定と改善
- 部品交換の優先度決定

### 3. **バッテリー管理**
- 電圧差による性能影響の確認
- 充電タイミングの最適化

### 4. **長期追跡**
- 使用による劣化の監視
- メンテナンス周期の決定

## 🚨 注意事項

1. **車輪は必ず浮かしてください**
   - 負荷なし状態での純粋な比較

2. **同一条件でテスト**
   - 同じ場所、同じ時間帯
   - バッテリー残量を揃える

3. **複数回測定推奨**
   - 日を変えて再測定
   - 一時的な要因を排除

4. **環境要因の考慮**
   - 温度、湿度の影響
   - 振動や電磁波の影響

## 📊 テスト項目

### 簡易テスト
- HIGH_SPEED_BASE, 100, 120, 140の比較
- 3秒×4速度 = 約15秒で完了
- 即座に結果表示

### 包括的テスト
- 50～255の14種類の速度設定
- 各8秒間の詳細測定
- 以下のデータを記録:
  - 実際の速度・パワー
  - 達成率
  - 変動値（安定性）
  - 最大値

## 📈 出力ファイル

### CSVファイル
`storage/motor_test_results_YYYYMMDD_HHMMSS.csv`

### 含まれるデータ
- `test_speed`: 設定速度
- `avg_speed_a/b`: 実際の平均速度
- `avg_power_a/b`: 平均パワー使用率
- `achievement_rate_a/b`: 達成率
- `max_speed_a/b`: 最大速度
- `speed_std_a/b`: 速度変動

## 🎯 使い分け

### 簡易テスト向き
- ✅ 設定値の効果を素早く確認したい
- ✅ 現在の性能を知りたい
- ✅ 複数の候補値を比較したい

### 包括的テスト向き
- ✅ 最適な設定値を科学的に決めたい
- ✅ 詳細なデータが必要
- ✅ モーターの限界を正確に把握したい

## 💡 テスト結果の読み方

### 達成率
- **0.9以上**: 優秀（設定値の90%以上を実現）
- **0.8-0.9**: 良好
- **0.7-0.8**: やや低下
- **0.7未満**: 大幅低下

### パワー使用率
- **95%以上**: 限界に近い
- **80-95%**: 適切な範囲
- **80%未満**: 余裕あり

### 推奨設定値の判定基準
1. パワー使用率 < 90%
2. 達成率 > 0.8
3. 上記を満たす中で最も高い実速度

## 🔧 カスタマイズ

### 測定時間の変更
```python
# quick_motor_test.py
quick_motor_check(speed=100, duration=10)  # 10秒に延長

# test_motor_limits.py
self.test_single_speed(speed, duration=15)  # 15秒に延長
```

### テスト速度の変更
```python
# test_motor_limits.py内のtest_speedsリストを編集
test_speeds = [
    (80, "カスタム1"),
    (110, "カスタム2"),
    # ... 追加
]
```

## 🚨 注意事項

1. **車輪は必ず浮かしてください**
   - 負荷なし状態でのモーター限界を測定
   
2. **テスト中は監視してください**
   - 異常音や過熱がないか確認
   
3. **長時間連続使用は避けてください**
   - モーター保護のため適度に休憩

4. **バッテリー残量を確認してください**
   - 低電圧時は正確な測定ができません

## 📋 トラブルシューティング

### データが取得できない
- SPIKEとの接続を確認
- バッテリー残量を確認
- プログラムを再起動

### 速度が出ない
- 車輪が浮いているか確認
- モーターの配線を確認
- 設定値が適切か確認

### 結果が不安定
- 測定時間を延長
- 環境の振動を減らす
- 複数回テストして平均を取る
