# モーターテストツール

`run_manual.py`や`constants.py`を変更せずにモーター性能をテストするツール群です。

## 📋 前提条件

⚠️ **重要**: 全てのテストは**車輪を浮かした状態**で実行してください

## 🚀 使用方法

### 1. 簡易テスト (推奨)
```bash
cd tests
python quick_motor_test.py
```

**特徴:**
- 最短5秒でテスト完了
- リアルタイム進捗表示
- 簡易判定機能
- 複数速度比較モード

### 2. 包括的テスト
```bash
cd tests
python test_motor_limits.py
```

**特徴:**
- 14種類の速度設定を自動テスト
- 詳細な統計データ収集
- CSVファイル出力
- 推奨設定値の自動計算

## 📊 テスト項目

### 簡易テスト
- HIGH_SPEED_BASE, 100, 120, 140の比較
- 3秒×4速度 = 約15秒で完了
- 即座に結果表示

### 包括的テスト
- 50～255の14種類の速度設定
- 各8秒間の詳細測定
- 以下のデータを記録:
  - 実際の速度・パワー
  - 達成率
  - 変動値（安定性）
  - 最大値

## 📈 出力ファイル

### CSVファイル
`storage/motor_test_results_YYYYMMDD_HHMMSS.csv`

### 含まれるデータ
- `test_speed`: 設定速度
- `avg_speed_a/b`: 実際の平均速度
- `avg_power_a/b`: 平均パワー使用率
- `achievement_rate_a/b`: 達成率
- `max_speed_a/b`: 最大速度
- `speed_std_a/b`: 速度変動

## 🎯 使い分け

### 簡易テスト向き
- ✅ 設定値の効果を素早く確認したい
- ✅ 現在の性能を知りたい
- ✅ 複数の候補値を比較したい

### 包括的テスト向き
- ✅ 最適な設定値を科学的に決めたい
- ✅ 詳細なデータが必要
- ✅ モーターの限界を正確に把握したい

## 💡 テスト結果の読み方

### 達成率
- **0.9以上**: 優秀（設定値の90%以上を実現）
- **0.8-0.9**: 良好
- **0.7-0.8**: やや低下
- **0.7未満**: 大幅低下

### パワー使用率
- **95%以上**: 限界に近い
- **80-95%**: 適切な範囲
- **80%未満**: 余裕あり

### 推奨設定値の判定基準
1. パワー使用率 < 90%
2. 達成率 > 0.8
3. 上記を満たす中で最も高い実速度

## 🔧 カスタマイズ

### 測定時間の変更
```python
# quick_motor_test.py
quick_motor_check(speed=100, duration=10)  # 10秒に延長

# test_motor_limits.py
self.test_single_speed(speed, duration=15)  # 15秒に延長
```

### テスト速度の変更
```python
# test_motor_limits.py内のtest_speedsリストを編集
test_speeds = [
    (80, "カスタム1"),
    (110, "カスタム2"),
    # ... 追加
]
```

## 🚨 注意事項

1. **車輪は必ず浮かしてください**
   - 負荷なし状態でのモーター限界を測定
   
2. **テスト中は監視してください**
   - 異常音や過熱がないか確認
   
3. **長時間連続使用は避けてください**
   - モーター保護のため適度に休憩

4. **バッテリー残量を確認してください**
   - 低電圧時は正確な測定ができません

## 📋 トラブルシューティング

### データが取得できない
- SPIKEとの接続を確認
- バッテリー残量を確認
- プログラムを再起動

### 速度が出ない
- 車輪が浮いているか確認
- モーターの配線を確認
- 設定値が適切か確認

### 結果が不安定
- 測定時間を延長
- 環境の振動を減らす
- 複数回テストして平均を取る
